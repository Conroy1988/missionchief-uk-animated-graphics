# TKB presentation standard

[Project home](../README.md)

- Canvas: `#09090c`; panels: `#111115` and `#19191f`.
- Primary text: `#f5f5f7`; secondary text: `#b1b1bd`.
- Brand red: `#ed263e`; primary button: `#c91e36` with white text.
- Signature: two parallel horizontal red bars. Use the existing TKB identity without introducing a character or portrait.
- Compact panels, restrained borders and clear typography. Preserve service colour meaning in preview labels.
- Keep focus indicators, labelled controls, responsive layouts and reduced-motion support.

The GitHub README uses a repository-owned SVG banner because GitHub controls its surrounding page chrome and does not allow custom page CSS. The interactive gallery carries the full theme.
