# Contributing

[Project home](README.md) · [Development guide](docs/DEVELOPMENT.md)

For a missing vehicle, include its exact MissionChief UK name, slot and service. For a visual problem, include the asset name, static or animated state, browser and a screenshot at normal map scale. For gallery problems, include the search/filter settings and screen size.

Open a [repository issue](https://github.com/Conroy1988/missionchief-uk-animated-graphics/issues). Do not include login details, session cookies or personal player information.

Keep production artwork original. Preserve transparency, native dimensions, naming and slot mapping. Follow the technical standards and run the relevant validation before proposing graphics changes. Code and artwork have separate licences; see [LICENSE.md](LICENSE.md).
